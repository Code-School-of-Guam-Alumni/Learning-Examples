# Ruby Object-Oriented Programming Reference

This reference combines the OOP ideas repeated across the Cohort 2 archive: objects with state, inheritance, modules/mixins, private methods, explicit errors, and JSON file persistence.

## Run and verify

```sh
ruby ruby/oop/reference.rb
```

The program uses a temporary directory, verifies the saved and loaded records, and removes the temporary file automatically.
