# Ruby Fundamentals Reference

This small program is the current reference for CSG lessons covering variables, conditionals, loops, arrays, hashes, methods, user-facing output, and simple decomposition.

## Run and verify

```sh
ruby ruby/fundamentals/reference.rb
```

The script raises an error if any built-in check fails and prints `Ruby fundamentals checks passed.` when the examples behave as expected.
