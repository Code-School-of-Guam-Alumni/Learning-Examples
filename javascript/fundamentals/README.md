# JavaScript Fundamentals Reference

This reference covers variables, strict equality, conditionals, loops, functions, array transformations, objects, promises, and `async`/`await` without requiring a framework.

## Run and verify

```sh
node javascript/fundamentals/reference.mjs
```

The original classroom tooling example remains available at the immutable [Cohort 2 `modern-js` commit](https://github.com/CSG-Live-July-2025/modern-js/tree/b13bb02996a395eb24ab511b7f0058f192622581).
