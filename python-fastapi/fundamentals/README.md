# Python Fundamentals Reference

This small program translates the Ruby and JavaScript fundamentals used throughout CSG into modern Python: dictionaries, lists, conditionals, comprehensions, functions, type hints, and explicit validation.

## Run and verify

```sh
python3 python-fastapi/fundamentals/reference.py
```

The example uses only the Python standard library. It is reconstructed because no exact standalone Python-fundamentals repository was preserved for the Cohort 2 recording.
